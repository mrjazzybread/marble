# Marble

This Rocq library
makes it easier to work comfortably with Rocq's
primitive integers
(which are unsigned 63-bit integers)
and primitive arrays
(which are persistent arrays, backed by a mutable array).

It offers a simple Hoare logic
that helps write and verify code
that uses integers, arrays,
and array-based data structures.

It offers ready-made support for loops of various kinds,
a range of operations on arrays,
as well as two array-based data structures,
namely vectors and priority queues.

For more information,
please read the [documentation](doc/documentation.md).
